Not built yet

What this console deliberately does not pretend to do.

Authentication

There is no login, because a static site cannot keep a secret. Anything in this page is readable by anyone who opens it. Host it behind HTTP auth, a private path, or run it locally until Supabase Auth is wired in.

Customer & supplier accounts

Tables exist in db/schema.sql (profiles, suppliers, customers via profiles) with row-level security already written. Needs the database.

Quotations & BOQ inbox

Front-end forms currently confirm and discard. quotes, quote_items, projects and project_files are modelled and ready.

File uploads

DWG, PDF and ZIP uploads need object storage. CKAStore.files.upload() is the single call site — swapping to Supabase Storage, S3 or Cloudinary changes one function.

Live bidding

The board on the public site is a simulation. Real bids need supplier_bids plus a realtime channel.

Image uploads

New images must be added to assets/img/ and referenced by path. Direct upload arrives with storage.
